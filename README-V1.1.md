# K.I.R.A. Core Experience V1.1

## Aggiornamento consigliato — SOLO FILE MODIFICATI
1. Carica `public/app.js` e `public/style.css` nel repository GitHub, nei percorsi identici.
2. Non sostituire `wrangler.jsonc` se nel tuo repository contiene gia il vero database_id D1.
3. Non toccare D1, secret, accessi o migrazioni.
4. Fai commit e attendi il nuovo deploy Cloudflare.
5. Apri K.I.R.A. con Ctrl+F5.

## Che cosa cambia
- Home Core AI animata e menu a scomparsa.
- Conversazione creata automaticamente al primo messaggio.
- Cronologia e Project Lab facilmente accessibili.
- Dettatura browser se supportata, voce di risposta selezionabile nel Control Center.
- Le aree esistenti (memoria, progetti, attivita, impostazioni) restano disponibili.

## Limiti dichiarati
Il Core e una visualizzazione CSS, non un riconoscimento vocale sempre acceso. L'input da microfono usa Web Speech API solo quando disponibile. Il Project Lab continua a salvare file testuali e versioni; non esegue ancora CAD o AI agent tools. Nessuna spesa obbligatoria aggiunta.
